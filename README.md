## WorkGram (Demo Project)

WorkGram is a full stack job portal web application designed to streamline the hiring process for candidates and recruiters. It provides a clean, intuitive interface for:

🎯 Job seekers to browse job listings, apply, and track their applications

🏢 Recruiters to post jobs, manage applicants, and browse talent

📊 A central dashboard to monitor interviews, job offers, and application statuses

Built with Next.js, WorkGram offers a responsive, user first experience with real time job updates and profile management.
